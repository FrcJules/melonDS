# Third-party software in melonDS Switch

The `.nro` is a static link of melonDS (GPL-3.0-or-later) and the libraries below. Their license texts must ship with
binary releases (folder `licenses/` of the release archive).

|---|---|---|
| melonDS core, FreeBIOS | GPL-3.0-or-later | https://github.com/melonDS-emu/melonDS |
| Teakra (DSi DSP) | MIT (`src/teakra/LICENSE`) | https://github.com/wwylele/teakra |
| libnx | ISC | https://github.com/switchbrew/libnx |
| SDL2 | zlib | https://github.com/devkitPro/SDL |
| SDL2_ttf | zlib | https://github.com/libsdl-org/SDL_ttf |
| FreeType | FreeType License (FTL), chosen here | https://freetype.org |
| HarfBuzz | "Old MIT" | https://github.com/harfbuzz/harfbuzz |

| zlib | zlib | https://zlib.net |

| Mesa (EGL, GLES, nouveau) | MIT | https://gitlab.freedesktop.org/mesa/mesa |
